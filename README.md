# Flask-launch-extension
Creates a virtual workspace, downloads all necesary Flask files into the current users documenty directory and runs any Flask project open in VS code editor.<br>
Makes its own embedded python, pip and venv.<br>
No admin rights needed.
# Requirements
Windows 10/11.<br>
VS code 1.3 or newer.<br>
# Instalation
Download the latest .vsix file from releases and import it in VS code extension manager.
# How to use
Just click the new play button in top right of your code editor. The extension will get all required resources and launch your testing server.
